## 3. Motion reference

### Hero entrance

```css
.hero-animate {
  opacity: 0;
  transform: translateY(24px);
  animation: heroFadeUp 0.7s cubic-bezier(0.16, 1, 0.3, 1) forwards;
}

.hero-delay-0 { animation-delay: 0.1s; }
.hero-delay-1 { animation-delay: 0.2s; }
.hero-delay-2 { animation-delay: 0.35s; }
.hero-delay-3 { animation-delay: 0.5s; }
.hero-delay-4 { animation-delay: 0.65s; }
.hero-delay-5 { animation-delay: 0.9s; }
```

### Scroll reveal

- IntersectionObserver: `rootMargin: '-60px 0px'`, `threshold: 0.15`
- Transition timing: ok. `500ms`
- List stagger: `80ms` per item

### Hover rules

- Primary button hover: `--color-primary-light`, lift `translateY(-2px)`, glow `rgba(0, 211, 242, 0.3)`
- Primary button active: shadow `rgba(0, 211, 242, 0.2)`
- Cards: hover idzie przez border emphasis i controlled shadow, bez mocnych dekoracyjnych haloes
- Inline links: hover przez kolor, nie przez dodatkowe ozdobniki poza systemem

### Reduced motion

```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

## 4. Section notes

### Global background

- Body background uses `public/brand-bg.jpg` with dark teal overlay and small brand radials
- The photo is scene texture, not foreground content
- Text-heavy surfaces must still use explicit card/panel backgrounds over it
- Decorative color is capped to cyan primary + violet secondary. No section-level green/yellow/orange accents.

### About

- Background: `section-surface-about`
- Trust bullets siedza obok glownego copy i uzywaja only primary/accent on icon + card surface
- Stats separator bierze `--color-border`

### Skills

- Category groups mapuja sie only to primary/accent
- Category dots i icon glows nie wprowadzaja dodatkowych hue

### Projects

- `--card-gradient` sklada sie tylko z aktywnych brand tokens
- `--card-surface` daje karcie ciemna surface baze bez osobnych green/yellow surfaces
- `project-icon-tile` shows project assets from `public/project-icons/`
- Hover ring animuje tylko `opacity`
- Tech pills uzywaja dark translucent surface i system border

### Pricing

- Surface: `--color-bg-card`
- Interactive emphasis: `--color-primary`
- CTA w kartach trzyma ten sam kontrast co reszta przyciskow

### Contact

- Form card: `.contact-form-card`, tinted by primary
- Contact method rows: `.contact-method`, primary/accent only
- Inputs: focus ring `rgba(0, 211, 242, 0.1)`
- Social buttons: `--surface-card`, system border

### Footer

- Border top: `--color-border`
- Brand highlight: `--color-primary`

## 5. Accessibility checklist

### Focus system

```css
:focus-visible {
  outline: 2px solid var(--color-primary);
  outline-offset: 3px;
  border-radius: 4px;
}

.btn:focus-visible {
  outline: 2px solid var(--color-primary-light);
  outline-offset: 3px;
  box-shadow: 0 0 0 4px rgba(0, 211, 242, 0.15);
}

.input-field:focus-visible {
  border-color: var(--color-primary);
  box-shadow: 0 0 0 3px rgba(0, 211, 242, 0.1);
  outline: none;
}
```

### Contrast summary

| Pair | Status |
|---|---|
| `--color-text` on `--color-bg` | PASS |
| `--color-text` on `--color-bg-card` | PASS |
| `--color-text-muted` on `--color-bg-card` | PASS |
| `--color-text-subtle` on `--color-bg-card` | PASS for supporting copy; nie uzywac jako jedyny sygnal stanu |
| `--color-primary` on `--color-bg` | PASS |
| `--color-primary-content` on `--color-primary` | PASS |
| `--color-error` as small-text color on dark background | FAIL; trzymac go jako semantic accent, nie body copy |

### Structural rules

- Skip link ma zostac widoczny po focusie
- `main`, `nav`, `section`, `article`, `footer` maja zostac semantyczne
- Form validation uzywa `aria-invalid` i `aria-describedby`
- Mobile menu steruje `aria-expanded`

## 6. Performance budget

| Metric | Target | Notes |
|---|---|---|
| LCP | `<= 2.0s` | hero portrait jest glownym kandydatem |
| CLS | `<= 0.05` | stabilne image dimensions i font loading |
| INP | `<= 150ms` | low-interaction marketing page |
| Total page weight | `<= 350KB` compressed | z portretem i fontami |
| CSS | `<= 30KB` compressed | Tailwind purge + niewiele custom CSS |
| JS | `<= 20KB` compressed | menu, observer, contact, toggle |
| Fonts | `<= 110KB` | trzy rodziny, tylko potrzebne weights |
| SVG icons | `<= 15KB` total | tree-shaken imports |
| Hero portrait outputs | lekkie responsive assets | aktualny hero to zoptymalizowany obraz, nie placeholder CSS |

### Hero asset notes

- Uzywac `astro:assets` responsive outputs
- `loading="eager"` i `fetchpriority="high"`
- Preload w `Layout.astro` musi odpowiadac tym samym params co hero image
- Zachowac aspect ratio i rozmiary z hero container, zeby nie generowac CLS
