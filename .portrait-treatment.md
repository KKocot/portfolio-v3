# Portrait Treatment Brief

## 1. Wybrany kierunek: C (Subtle cool tint + vignette) — zmodyfikowany

Opcja C daje najlepszy balans miedzy autentycznoscia a integracja z refined mono palette. Zachowujemy rozpoznawalnosc twarzy (klient widzi prawdziwego czlowieka), jednoczesnie redukujac cieplo czerwonych paneli w tle. Drobna modyfikacja vs czyste C: dodaje silniejsza desaturacje (60% zamiast 40%) i rezygnuje z hue-rotate na rzecz sepia(0.15) + brightness shift, co daje bardziej naturalny cool-cast bez plastikowego niebieskiego odcienia.

Odrzucone opcje:
- A (grayscale) — zbyt sterylny, SMB klient oczekuje ciepla osobistego kontaktu
- B (duotone violet) — ryzyko "edgy tech startup" zamiast profesjonalnego freelancera
- D (bg replacement) — wymaga zewnetrznego edytora, poza scope

## 2. CSS Filter Values

```css
.portrait-img {
  filter: grayscale(0.6) contrast(1.12) brightness(0.88) sepia(0.15) saturate(0.7);
  transition: filter 400ms ease-out;
}

.portrait-img:hover {
  filter: grayscale(0.3) contrast(1.08) brightness(0.92) sepia(0.08) saturate(0.9);
}

@media (prefers-reduced-motion: reduce) {
  .portrait-img {
    transition: none;
  }
}
```

Efekt: portret zyskuje chlodny, lekko desaturowany ton — bliski monochromatycznemu ale z zachowaniem odcieni skory i granatowego garnituru. Czerwone panele w tle staja sie ciemno-szare/neutralne. Sepia(0.15) dodaje subtelne cieplo zeby twarz nie byla trupio-szara.

## 3. Container Treatment

```css
.portrait-container {
  /* Wymiary zachowane z obecnego golden mesh */
  /* Mobile: w-72 h-[360px], SM: w-80 h-[400px], LG: w-[380px] h-[480px] */

  border-radius: 16px;          /* rounded-2xl, jak obecny */
  overflow: hidden;
  position: relative;
  background: var(--color-bg-card);  /* #141414 fallback przed zaladowaniem img */

  /* Subtle border zamiast ostrego edge */
  border: 1px solid rgba(139, 92, 246, 0.15);  /* violet hint */

  /* Outer glow — zastepuje wewnetrzny mesh glow */
  box-shadow:
    0 0 40px rgba(139, 92, 246, 0.08),   /* violet ambient */
    0 8px 32px rgba(0, 0, 0, 0.4);        /* depth shadow */
}

/* Vignette overlay — maskuje edges zdjecia, szczegolnie problematyczne tlo */
.portrait-container::after {
  content: '';
  position: absolute;
  inset: 0;
  border-radius: inherit;
  pointer-events: none;
  z-index: 2;
  background: radial-gradient(
    ellipse at 50% 40%,     /* centrum lekko wyzej — na twarzy */
    transparent 45%,
    rgba(10, 10, 10, 0.5) 85%,
    rgba(10, 10, 10, 0.85) 100%
  );
}
```

Vignette robi duza robote: sciemnia krawedzie (glownie gorne rogi z czerwonymi panelami) i naturalnie przechodzi w ciemne tlo strony `#0A0A0A`. Twarz i gorna czesc garnituru pozostaja czytelne.

## 4. Hover State

- Filter: desaturacja spada z 60% do 30%, lekko jasniej i cieplej — "reveal" efekt
- Transition: 400ms ease-out (medium enter/exit bracket)
- Opcjonalnie: `transform: scale(1.02)` na kontenerze (transition 300ms ease-out)
- Vignette (::after) NIE zmienia sie na hover — stabilny frame

```css
.portrait-container:hover .portrait-img {
  filter: grayscale(0.3) contrast(1.08) brightness(0.92) sepia(0.08) saturate(0.9);
  transform: scale(1.02);
}

.portrait-container:hover {
  border-color: rgba(139, 92, 246, 0.3);
  box-shadow:
    0 0 60px rgba(139, 92, 246, 0.12),
    0 8px 32px rgba(0, 0, 0, 0.4);
}
```

## 5. Responsive

| Breakpoint | Kontener | Img | Notatki |
|---|---|---|---|
| Mobile (<640px) | `w-72 h-[360px]` (288px) | `object-fit: cover; object-position: top center;` | Centrowany. NIE pelna szerokosc — zachowaj proporcje portretu |
| SM (640-1023px) | `w-80 h-[400px]` (320px) | j.w. | Centrowany |
| LG (1024+) | `w-[380px] h-[480px]` | j.w. | Lewy side gridu, justify-start |

Zachowujemy obecne wymiary kontenera 1:1 — zdjecie wchodzi w miejsce golden mesh bez zmiany layoutu. `object-fit: cover` + `object-position: top center` gwarantuje ze twarz jest zawsze widoczna (nie obcieta od gory).

## 6. Badge "Available for work"

Pozycja: bez zmian — floating, `absolute -bottom-4 right-0 sm:-right-4`. Lezy na rogu portretu, lekko wychodzi poza kontener. Z-index powyzej vignette (>= 3).

Jedyna zmiana: dodac `z-10` do badge (obecny stacking context moze byc zakryty przez ::after vignette).

## 7. Ghost Initials "KK"

**USUNAC.** Zdjecie to prawdziwy brand signal — inicjaly sa redundantne i kolidowaly by z twarz w tle. SVG grid pattern rowniez do usuniecia (nie ma sensu nad zdjeciem). Caly wewnetrzny content kontenera (SVG, ghost initials div) zastapiony przez `<img>`.

## 8. Hero Glow

Obecny hero-glow (violet radial-gradient za kontenerem) — **zachowac**, lekko przesunac w strone portretu.

```css
/* Obecne wartosci */
.hero-glow {
  background: radial-gradient(
    ellipse at center,
    rgba(124, 58, 237, 0.1) 0%,
    rgba(124, 58, 237, 0.03) 40%,
    transparent 70%
  );
}
```

Bez zmian w kolorze. Violet glow za zdjeciem daje efekt "luny" ktora laczy portret z reszta palette. Dziala lepiej ze zdjeciem niz z meshem bo dodaje depth.

## 9. Implementacja — struktura HTML

```astro
<!-- Portrait container — zastepuje golden mesh -->
<div class="portrait-container w-72 h-[360px] sm:w-80 sm:h-[400px] lg:w-[380px] lg:h-[480px] rounded-2xl overflow-hidden relative">
  <img
    src="/portrait.jpg"
    alt="Krzysztof Kocot — Full-Stack Developer"
    class="portrait-img w-full h-full object-cover object-top"
    loading="eager"
    decoding="async"
    width="380"
    height="480"
    fetchpriority="high"
  />
  <!-- Vignette overlay via ::after (CSS) -->
</div>

<!-- Badge pozostaje bez zmian, z dodanym z-10 -->
```

`loading="eager"` + `fetchpriority="high"` — portret jest LCP element, musi sie zaladowac natychmiast.

## 10. Performance

- Zdjecie: docelowo WebP/AVIF, max 80-100KB, rozmiar zrodlowy min 760x960px (2x dla retina)
- Astro `<Image>` component do rozwazenenia (automatyczna optymalizacja), ale wymaga importu
- `will-change: filter` na hover — NIE ustawiac domyslnie, tylko na :hover
- Brak dodatkowych requestow (SVG grid i ghost initials usuwane)

## 11. A11y

- `alt` text opisowy: "Krzysztof Kocot — Full-Stack Developer"
- Vignette ::after: decorative, nie wymaga aria
- Hover: czysto wizualny, nie zmienia contentu
- Contrast: badge text na tle badge-bg musi byc >= 4.5:1 (obecny ok)
